# Image Collection

During the 2021/22 harvest, UAV flights were conducted at an altitude of 10 meters over six corn farming areas located at the municipalities of Caarapó (MS) and Dourados (MS), Brazil. The UAV was a multirotor, model Phantom 4 Advanced, equipped with a 20-MP Sony camera (5472x3648 pixels). In total, 1,583 images were collected during the weed-prone phenological stages V3, V4 and V5, from which 1,391 contained weeds.

Each image collected with the UAV was annotated with LabelImg, a graphic image annotation tool to label object bounding boxes in images. Each bounding box label corresponds to a weed found in the plantation and its class (species). The same image can have multiple occurrences of weeds of the same or different species. We are considering remaining soybean plants as weeds because corn is the main crop. The resulting WEED6C-Dataset.
